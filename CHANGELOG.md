# Changelog

## 0.0.1

Initial release.

- Full-text search across Claude Code session transcripts (`Ctrl+Alt+S` / `Cmd+Alt+S`).
- Local index in VS Code extension storage — nothing leaves your machine.
- Phrase search, `pr:`/`since:` filters, and optional tool-call search (`!query`).
- Opens matched sessions in the right window, including across git worktrees.
